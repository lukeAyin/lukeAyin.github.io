每篇文档的内容约定

  1. 范围与基线： 源码提交、配置、涉及模块及当前核对范围。
  2. 结构与职责： 模块关系、进程/rank 边界和资源所有者；需要时使用 Mermaid。
  3. 调用与数据流： 入口、关键接口、对象转换、输入输出，区分消息传递与函数调用。
  4. 状态与时序： 状态由谁维护，何时更新；适用时描述依赖、异步完成和同步位置。
  5. 配置分支： 哪些配置改变路径，以及未覆盖的分支。
  6. 仿真边界： 真实保留部分、设备适配部分、代价输入、完成事件和观测点。
  7. 设计依据与待验证项： 将已核对生产实现、现有原型行为、拟议方案分别标识。
  8. 关联功能文档： 链接职责与具体例子，避免重复说明。
