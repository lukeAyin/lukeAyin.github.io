## 每篇文档的内容约定

1. **范围与状态：** 学习阶段、源码提交、适用配置、已学习/待核对范围。
2. **功能与概念：** 解决什么问题，解释相关术语和对象职责。
3. **输入输出：** 关键字段、shape、单位、前置条件和调用方责任。
4. **行为流程：** 正常路径、状态变化、资源变化以及相关边界情况。
5. **具体例子：** 用小输入推演步骤，注明哪些来自源码、手算或实际运行。
6. **源码定位：** 路径、类和函数名，说明每个入口的作用。
7. **性能仿真影响：** 必须保留的真实行为、代价模型需要的信息、可替换的设备能力。
8. **证据与未决问题：** 运行记录或“仅源码核对”，已有结论的适用边界。
9. **关联架构文档：** 链接对应调用关系、数据流或时序图。

按内容复杂度合并小节，不为格式重复写相同内容。跨模块关系集中在架构文档，功能文档保留局部行为并引用它。
